# 任务日程：截止日期与重复

在一个窗口中查看所有笔记本里带日期的未完成任务，按“已逾期、今天、未来 7 天、更晚”分组。无需任何设置：直接读取你在普通 `- [ ]` 任务项里写的日期。核心功能免费开源（MIT），无遥测，除本机思源内核外不发起任何网络请求。

## 免费功能
- 点击顶栏日历图标（或运行命令“打开任务日程”）。
- 识别任务项中的日期：`2026-12-01`、`due:2026-12-01`、`@2026-12-01`、`2026/12/01`、`2026.12.01`、日历表情加日期，以及 `2026年12月1日`。若一个任务有多个日期，优先取紧跟在标记（`due:`、`@`、日历表情）后的日期，否则取第一个有效日期。
- 分组显示，并标注距今天数和所在文档。
- 勾选即完成（保留嵌套子任务），点击文字跳转到原文。
- 一键复制 Markdown 日程。

## Pro（可选，一次性授权）
- 重复任务：在任务里写规则，例如 `交房租 📅 2026-12-01 🔁 every month`。支持 `every day`、`every 3 days`、`every week`、`every 2 weeks`、`every weekday`、`every month`、`every year`（也可写 `repeat: weekly`）。完成后点击“添加下一次重复”，会在其下方插入带新日期的未勾选任务。月份按月末截断（1 月 31 日 重复到 2 月 28 日），错过的重复不会堆积成逾期。
- 导出带日期的任务为日历文件（.ics），含全天事件和重复规则，可导入苹果、谷歌、Outlook 日历。

免费版除你勾选的复选框外不会写入任何内容。Pro 的“添加下一次重复”只为每个已完成的重复任务插入一个新任务，并给原任务加上 `custom-agenda-rolled` 属性，保证不会重复生成。

## 安装
集市 → 插件，搜索“任务日程”。

## 开发
`npm install` 后运行 `node build.mjs` 生成 `index.js`；`npm test` 运行测试。
